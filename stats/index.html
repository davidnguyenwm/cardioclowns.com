Where the token comes from
  1. Open icloud.developer.apple.com/dashboard
  2. Pick the container, then switch the environment control beside its name to the one you want — tokens are scoped to it, and a Development token gets a flat 401 against Production
  3. Tokens & Keys → Add token, name it “website stats”
  4. Copy it here
The token is encrypted with your password (AES-GCM, 600k-round PBKDF2) before it touches this browser’s storage. It is never sent anywhere except Apple’s CloudKit API.
