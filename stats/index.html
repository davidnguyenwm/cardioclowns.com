Where the token comes from
  1. Open icloud.developer.apple.com/dashboard
  2. Pick the container → Tokens & Sharing → API Tokens
  3. Add token, name it “website stats”, leave the sign-in callback empty
  4. Copy it here
The token is encrypted with your password (AES-GCM, 600k-round PBKDF2) before it touches this browser’s storage. It is never sent anywhere except Apple’s CloudKit API.
